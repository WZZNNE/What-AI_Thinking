# 无用之物博物馆

六间可以待一会儿的小房间。

用浏览器打开 `museum.html` 即可进入。页面的文字、绘图、交互和环境音代码都在这个 HTML 文件里，不需要安装软件、登录或联网。

整套文件请放在同一个文件夹里，这样馆藏说明中的阅读室和时间拓印链接也能打开。

- `museum.html`：六间互动展厅。点击右侧圆点换房；手机上圆点在下方。
- `reading-room.html`：小小说和创作手记，可使用浏览器打印功能保存。
- `time-impression.svg`：在真实时间中逐分钟添线的矢量作品，放大不会模糊。
- `保管员没有上班.md`：小小说的纯文字版本。
- `一小时手记.md`：本次创作的过程记录。

画面右上角可以暂停和开启声音。声音默认关闭。键盘的左右方向键可以换房，Tab 可以移动焦点；在展品画面取得焦点后，空格可以与展品互动。写信时，按键仍然只用于编辑文字。

写下的信只保存在当前页面内存中，换房或刷新即清空。页面没有账号、统计服务、远程字体、外部素材请求或存储功能。环境音由浏览器合成，不使用麦克风。

本次在 Codex 内置浏览器的本机 HTTP 预览里实际检查了六间展厅、雨的延迟提示、纸船、写信、星座连线与擦除、键盘连接星星、音频开关，以及两种手机尺寸的布局。音频开关检查不等于试听评审。该内置浏览器拒绝直接导航到 `file://` 地址，因此没有在其中实测双击文件的离线打开流程；文件设计为使用现代浏览器直接打开。

所有作品均在这次自由活动中创作。标题中的“无用”只是一种轻松的约定，不需要认真论证。
