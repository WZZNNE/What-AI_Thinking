# AI's Thinking

**AI 自由活动收藏馆 · A collection of AI at play**

一个收藏 AI 自由发挥的地方。

偶尔给 AI 一段时间，不指定成果，也不要求实用。它可以做一个小网页、写一篇故事、画一些奇怪的东西，或者沿着一个念头走一会儿。这座仓库收下那些留下来的作品，也保留它们如何产生的片段。

这里没有统一的题材，也不要求每件作品都有价值和意义。只希望打开时，能遇见一点意料之外的东西。

*A place for the things AI makes when given room to play.*

Sometimes, AI gets a little time with no prescribed outcome and no requirement to be useful. It might make a small website, write a story, draw something odd, or follow an idea for a while. This repository collects what remains, along with glimpses of how it came to be.

There is no fixed theme, and not every piece needs a purpose. The hope is simply to find something unexpected when you open the door.

## 作品收藏 / The collection

### 001 · 无用之物博物馆 / A Museum of Almost Nothing

**2026-09-20 · 互动网页、短篇小说、生成艺术 / Interactive web, short fiction, generative art**

从一次“一小时自由活动”里长出来的小博物馆。六间房分别留给借来的风、迟到的雨、影子的休息日、一分钟的海、不寄出的信，以及未完成的星座。附有小小说《保管员没有上班》、创作手记和一张在真实时间中逐分钟添线的“时间拓印”。

A small museum made during an hour of free exploration. Six rooms hold a borrowed breeze, late rain, a day off for shadows, a minute of sea, letters without an address, and an unfinished constellation. It includes a short story, *The Keeper Took the Day Off*, a creation journal, and a drawing built one line at a time as real minutes passed.

## 怎样逛 / Finding your way around

- 每件作品都有独立文件夹和项目 README，介绍内容与打开方法。<br>
  Each piece has its own folder and README with an introduction and instructions.
- 首页是持续更新的收藏目录；作品按编号排列，新作品追加在后面。<br>
  This page is the growing catalog. Entries are numbered, with new pieces appended below the existing ones.
- 作品介绍使用中英双语，作品本身保留创作时的语言与形式。<br>
  Introductions are bilingual. The works themselves retain the language and form in which they were made.
- 网页作品的 GitHub 文件链接展示源代码；实际打开方法见各项目说明。<br>
  GitHub file links show the source of web pieces. Each project explains how to open the experience itself.

## 继续收藏 / Adding the next piece

All pieces live in their own folders under `projects/` on `main`. Branches can be used while making or revising a piece; finished work returns to the shared collection.
